环境变量配置说明

用途：为 `authcode_to_openid.py` 提供默认参数，便于无需在命令行逐项传参即可调用根据付款码查询 openid 接口。

快速配置指南（Windows）
- PowerShell（当前会话有效）：
  - `$env:WX_APPID="wx1234567890"`
  - `$env:WX_MCH_ID="1900000109"`
  - `$env:WX_SUB_MCH_ID="1900000110"`
  - `$env:WX_AUTH_CODE="123456789012345678"`
  - `$env:WX_API_KEY="your_v2_key"`
  - `$env:WX_SUB_APPID="wx_sub_abcdef"`（可选）
- CMD（当前会话有效）：
  - `set WX_APPID=wx1234567890`
  - `set WX_MCH_ID=1900000109`
  - `set WX_SUB_MCH_ID=1900000110`
  - `set WX_AUTH_CODE=123456789012345678`
  - `set WX_API_KEY=your_v2_key`
  - `set WX_SUB_APPID=wx_sub_abcdef`
- 用户级持久化（PowerShell/CMD）：
  - `setx WX_APPID "wx1234567890"`
  - `setx WX_MCH_ID "1900000109"`
  - `setx WX_SUB_MCH_ID "1900000110"`
  - `setx WX_AUTH_CODE "123456789012345678"`
  - `setx WX_API_KEY "your_v2_key"`
  - `setx WX_SUB_APPID "wx_sub_abcdef"`
  - 说明：`setx` 需新开终端后生效；敏感信息建议仅设为会话变量。

脚本读取的环境变量（位置参考 `根据付款码获取openid/authcode_to_openid.py:76-82`）：
- `WX_APPID`：服务商的 `appid`（必填）
- `WX_MCH_ID`：服务商商户号 `mch_id`（必填）
- `WX_SUB_MCH_ID`：子商户号 `sub_mch_id`（必填）
- `WX_AUTH_CODE`：微信付款码 `auth_code`（必填）
- `WX_API_KEY`：微信支付 V2 密钥（必填，用于生成签名）
- `WX_SUB_APPID`：子商户 `sub_appid`（选填；当子商户绑定多个 appid 时必填）

脚本调用示例：
```
python d:\code\工具\根据付款码获取openid\authcode_to_openid.py
```
可选参数：
- `--sign-type MD5|HMAC-SHA256`（默认 `MD5`）
- `--dry-run`（仅打印请求 XML 与 URL，不发起网络请求）

.env 文件读取：
- 支持通过 `--env-file <路径>` 从 `.env` 文件加载上述环境变量，若系统环境已存在同名变量则不覆盖。
- `.env` 文件示例：
```
WX_APPID=wx1234567890
WX_MCH_ID=1900000109
WX_SUB_MCH_ID=1900000110
WX_AUTH_CODE=123456789012345678
WX_API_KEY=your_v2_key
# 可选：当子商户绑定多个 appid 时提供
WX_SUB_APPID=wx_sub_abcdef
```
- 执行示例：
```
python d:\code\工具\根据付款码获取openid\authcode_to_openid.py --env-file d:\code\工具\根据付款码获取openid\.env
```
 - 解析规则：支持 `export KEY=VALUE` 前缀、忽略 `#` 注释、支持用单/双引号包裹值；同名系统变量不被覆盖。

接口使用注意：
- 当子商户号绑定多个 `appid` 时必须提供 `sub_appid` 才会返回 `sub_openid`。
- 查询后，该付款码仅允许当前商户号发起扣款，直至付款码更新。
- 本接口仅用于获取 `openid`；若后续涉及资金、积分等资产扣减，需做二次身份校验（短信验密、会员密码等）。

安全提示：
- 请妥善保管 `WX_API_KEY`，避免写入代码仓库或持久化到系统环境。
 - `.env` 文件建议加入忽略列表，不要提交到版本库。

常见问题
- 运行报错“缺少参数: WX_***”：说明必填变量未配置；可在命令行传参或通过环境变量/.env 提供。
- `.env` 未生效：确认使用了 `--env-file <路径>`，并检查键名与脚本所需一致；已有同名系统变量不会被覆盖。
- 验证配置是否正确：使用 `--dry-run` 查看请求 XML 与目标 URL，不会触发网络请求。
