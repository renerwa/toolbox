# 中石化通信报文解析器

基于《加油机与 PC 机通讯数据接口协议（试行稿 V1.1）》的本地网页版报文解析工具。

## 使用

直接打开 `index.html`，粘贴完整通信日志或纯十六进制报文，然后点击“解析并添加”。所有解析均在浏览器本地完成。

## 能力

- 自动从日志中提取 `FA` 报文。
- 按两字节压缩 BCD 读取有效数据长度。
- 支持有 CRC、无 CRC、CRC 错误及转义报文。
- 自动合并日志不同阶段记录的同一业务帧。
- 解析旧版 V1.1 全部标准命令字及请求/响应变体。
- 对 96 字节成交记录按语义分组展示。
- 保留字段偏移、原始字节、解析值和协议说明。
