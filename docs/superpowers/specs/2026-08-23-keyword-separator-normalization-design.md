# 关键词分隔符自动换行设计

## 目标

优化 Google Trends 链接生成页面的关键词输入框。用户键入、粘贴或拖入文本时，将英文逗号 `,`、中文逗号 `，` 和竖线 `|` 立即替换为换行，使输入框内容与现有“每行一个关键词”的解析规则保持一致。

## 范围

- 仅修改 `Google Trends 链接生成/index.html` 中关键词输入框的输入处理。
- 保留现有的关键词去重、每五个分组、链接生成和统计逻辑。
- 分隔符前后的空格保持原样，不进行额外清理。

## 交互与数据流

1. 关键词输入框触发 `input` 事件。
2. 输入标准化函数将内容中的所有 `,`、`，` 和 `|` 替换为 `\n`。
3. 如果内容发生变化，更新输入框的值，并根据替换前的光标位置计算和恢复光标。
4. 使用标准化后的内容执行现有关键词解析，并刷新关键词数和链接数。

输入法组合输入期间不主动改写文本；组合结束触发输入事件后再完成标准化，避免干扰中文输入法。

## 异常与边界情况

- 连续分隔符会产生空行，现有解析逻辑会过滤空行。
- 同时包含换行、英文逗号、中文逗号和竖线的文本按同一规则统一。
- 英文逗号后的空格保留在下一行开头；现有解析逻辑在生成链接时仍会修剪关键词首尾空格。
- 未发生替换时不重设输入框值或光标。

## 验证

- 输入 `苹果，香蕉` 后显示为两行。
- 输入 `apple, banana` 后显示为两行，第二行保留行首空格。
- 输入 `苹果|香蕉` 后显示为两行。
- 粘贴混合内容 `苹果，香蕉|小米` 后显示为三行。
- 粘贴多行英文逗号分隔内容后，英文逗号全部显示为换行，关键词统计正确。
- 连续分隔符不会被识别为空关键词。
- 在文本中间输入分隔符后，光标保持在对应换行之后。
- 页面原有的统计和链接生成结果保持正确。
